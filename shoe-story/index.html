제목과 썸네일 제안

추천 제목: 연매출 50억 하던 사장이 길거리에서 구두를 신겨주는 이유

숫자 근거 확인 전 대안: 신발 도매하던 사장이 길거리에서 구두를 신겨주는 이유

이야기 중심 대안: 잘 팔던 신발 장사를 접고, 직접 고객 앞에 나선 사장님

50억은 녹음에서 설명한 과거 도매사업의 연매출이다. 현재 수제화 브랜드 매출이나 개인 소득으로 쓰지 않는다. 제목은 사용자 확정 전 가안이다.

썸네일 문구 가안: 잘 팔던 사장이 / 길거리로 나온 이유

사진 방향: 출연자가 실제 피팅을 돕는 모습과 신발을 함께 담는다. 상대방의 얼굴·신체를 과도하게 강조하지 않고, 출연자의 행동과 구두가 한눈에 보이는 구도. 참가자의 촬영·공개 동의 범위를 확인한다.

공장 대안 컷: 구두를 직접 살펴보거나 마무리 작업을 하는 출연자. 현재 재기 성과가 확인되기 전 ‘다시 대박’ 같은 문구는 쓰지 않는다.

실제 촬영 동선

기본안: 성수동 거리 콘텐츠 촬영 → 협업 수제화 공장 → 주문·콘텐츠를 확인할 작업 공간 → 같은 자리에서 재도전 이야기.

거리는 미팅에서 거론된 곳이다. 공장은 주소와 방문 가능 시간을 확인해야 하며 출연자 소유라고 단정하지 않는다.

출연자가 사무실을 따로 쓰지 않으면 허가받은 작업 테이블에서 화면·자료 인터뷰를 한다. 이번 편에 집·호텔·와인 장면을 새로 넣지 않는다.

공장 작업 가능 시간이 더 이르면 공장부터 촬영하고, 편집은 거리에서 시작한다.

모임·앰버서더 미팅은 실제 일정이 있는 경우만 추가한다. 미팅에서 제안한 대규모 워킹 행사는 현재 실행 여부가 확인되기 전 기본 동선에 넣지 않는다.
