# 사찍남 현장 카드

휴대폰에서 사용하는 촬영 질문 및 답변 확보 체크리스트.

## 사용

장소별 필수 질문을 보고, 필요한 답을 확보했을 때 체크합니다. 메모와 체크는 브라우저 localStorage에 저장되며 서버로 전송하지 않습니다. 기기 간 동기화는 없습니다.

## 배포

GitHub Pages: main 브랜치 루트에서 배포합니다. 사이트와 소스는 공개입니다.

## 개발

빌드 없이 HTML, CSS, JavaScript로 작동합니다. 로컬 확인은 `python3 -m http.server 8000` 실행 후 브라우저에서 열면 됩니다.
